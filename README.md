# AI Voice Studio

AI Voice Studio is an AI-powered voice platform.

## Core Features

- AI Voice Cloning
- Text-to-Speech
- AI Voice Conversation
- Voice Library
- Audio History

## Technology Stack

- Python
- FastAPI
- React
- TypeScript
- PostgreSQL
- OpenAI API
- ElevenLabs API
- Docker

## Project Structure

- frontend: React application
- backend: FastAPI application
- PostgreSQL: Database
- infrastructure: Deployment configuration
